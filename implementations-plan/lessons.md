# Lessons

Generalizable gotchas promoted from closed plans, one line each, linking to the archived detail. Budget: about 8 KiB; prune on every promotion.
- Chrome's Local Network Access **is** testable in headless Playwright: launch with `--ip-address-space-overrides=<page origin>=public` (a loopback-served page is otherwise same-address-space and ungated), deny with `grantPermissions([], { origin })`, grant with `['local-network-access']`. This corrects [presto-mine phase 2](presto-mine/lessons/phase-2.md) ("headless does not block", "denied cannot be produced"); the technique is Presto's own `lna.real.spec.ts`. Before calling a browser behaviour untestable, read how the dependency's own repo tests it. ([yacana-feedback-pass](yacana-feedback-pass/plan.md), Fact 19)
- **A check after `await` is not a check after the event loop turned.** A synchronous stretch inside an awaited call leaves posted messages queued; a permission read in the continuation sees the world before them. Take one task turn (`MessageChannel`: a realm's never-transferred ports are one FIFO) before a check whose answer a message can change. `yacana-feedback-pass/lessons/phase-8.md`.
- **Authorize at dispatch, not at enqueue.** Anything queued behind a promise that carries a capability re-reads the permission when it finally runs; moving the withdrawal to the front of the queue is half a fix. `yacana-feedback-pass/lessons/phase-8.md`.
- **The claim that closes an epoch carries one more nullifier**: `record_claim` initializes the next epoch's `PublicImmutable`. A first-contact claim has 4, the closing one 5 — the "5 nullifiers once" of the polish plan. `yacana-feedback-pass/lessons/phase-8.md`.
- **A second `document` is not a second React root**: portals, document-level listeners and pointer-down flags follow the global document; anything in a Document Picture-in-Picture window names its portal container and is tested in a real second document (an iframe in jsdom). `yacana-feedback-pass/lessons/phase-8.md`.
- **A shard failure the test alone cannot reproduce is the shard's history**: bisect what ran before it, keep the traces, read the effect's shape; six bisect runs on commits said nothing. `yacana-feedback-pass/lessons/phase-8.md`.
- **Anything hashed from a proof's raw fields needs one encoding per value**: bb's in-circuit Goblin decoder accepts a base-field coordinate `c` spelled `c + q` (barretenberg#1607); the native codec refuses it. Range-check the limbs and compare them below q before hashing. `archive/canonical-proof-encoding/plan.md` §2.
- **The toolchain is not on `bun run`'s PATH here**: prefix `~/.aztec/versions/<pin>/bin` and its `node_modules/.bin`, or `vk-pinning.test.ts` fails on `aztec-nargo` and gates read wrong. A Chonk VK's first field is its `log n`; `aztec test` starts TXE on the fixed port 8081 (probe it, never kill it). `archive/canonical-proof-encoding/lessons/phase-1.md`.
- **An account's first claim carries two note hashes** (the delivery handshake's and the mint's): record an example claim from an account's second claim. The site serves every `deployments/witnesses/*.jsonl` by rollup version, so a relaunch on the same version moves the old archive out of that folder. `archive/canonical-proof-encoding/lessons/phase-3.md`.
- **A conflicted PR gets no `pull_request` checks**: "no checks reported" right after a push means read `mergeable` before waiting. `archive/canonical-proof-encoding/lessons/phase-3.md`.
